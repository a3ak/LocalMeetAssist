Протокол создан по предыдущей версии транскрипта или списка спикеров. Последний успешный результат сохранён; рекомендуется повторить саммаризацию.

      

      
Измените все имена, перенесите фрагменты между карточками или перетащите карточку одного Speaker на другого для объединения. Изменения применятся только после общего сохранения.

      
Аудио автоматически преобразуется в рабочий PCM16 mono 16 кГц. Исходный файл после успешной проверки не сохраняется. Микрофон и системный звук можно загрузить последовательно; импорт mixed заменяет раздельную пару.

      

        

          
          
        

        
Если у старой встречи остался только Opus или MP3, при повторной обработке LocalMeetAssist автоматически восстановит рабочие PCM16 WAV. Сжатый исходник сохраняется.
