# Приватность — 0.1.0

Расширение соединяется только с локальным приложением через `ws://127.0.0.1:<port>/api/v1/ws`.
Аналитики, рекламы, облачной синхронизации и аудиозахвата нет.
Передаёт plugin-токен в hello, идентификатор установки, управляющий исходный URL встречи,
prompt_id при ответе, служебный URL действия и случайный command_id.
Общие CRUD endpoints не вызываются. Полные URL могут содержать параметры приглашений: расширение их не логирует.

`storage.local`: порт, токен, возраст/задержка обнаружения/локальная задержка остановки, install ID, отказ авторизации/версии протокола с номером отклонённого протокола, показанный prompt и диагностика уведомлений.
`storage.session`: URL/возраст/статус открытых вкладок, источник и controller, дедлайны, наблюдаемая активность/версия записи,
незавершённое действие. Сведения не синхронизируются и очищаются при завершении браузерной сессии.
Неподходящая управляющая вкладка при ручном выборе не отправляет свой URL серверу: сохраняется исходный URL встречи.

Разрешения tabs/webNavigation используются для текущих вкладок и навигации, не истории посещений.
Плагин может закрывать вкладки по явным кнопкам списка и открывать HTTP-интерфейс локального приложения.
Не читает содержание страниц, сообщения встреч, микрофон/системный звук.
Firefox категории browsingActivity/authenticationInfo отражают передачу URL/токена локальному приложению.
Удаление настроек удаляет секрет расширения; отзыв токена делается в приложении.
Сама запись/аудиоданные управляются приложением и сохраняются по его политике.

Для восстановления после полного перезапуска `storage.local` дополнительно хранит один минимальный
контекст браузерной записи: исходные URL/GLOB, client_id, recording_revision и версию локального формата.
Он не содержит tab.id, возраста страниц, токена или журнала команд. Удаляется по завершении/смене записи,
освобождении владения, отключении интеграции, смене порта/токена и очистке настроек. При обычном обрыве
канала сохраняется до проверки состояния сервера. Он не отправляется в облако и не логируется.
