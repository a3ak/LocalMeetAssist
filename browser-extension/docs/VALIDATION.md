# Выполненная проверка — 2026-10-07

Расширения **1.4.0**, опубликованная спецификация **1.0**, проводной протокол **1**.

Команда: `npm run package` — сборка Chrome/Firefox, синтаксис, manifests/CSP/ресурсы,
тесты и ZIP. Результат: **120/120 тестов пройдены**, без ошибок, пропусков и отмен.
Разрешения расширений сохранены. Нормативный docs/BROWSER_PLUGIN.md совпадает с предоставленным
документом побайтно. Проверены целостность ZIP, версии обеих сборок и содержимое вложенных пакетов.

Проверяются age/delay, decline без cooldown, дубликаты, F5/новый URL, продолжение по тому же GLOB,
выбор любой вкладки, ожидание 60 с, меню URL, команды и глобальный статус. Сохраняются тесты
минимального постоянного контекста, browser restart, устаревших восстановленных страниц,
абсолютных сроков worker/reconnect и отмены старого автоматического Stop при смене записи.

Новые проверки: hello/config версии 1; отсутствие stop_delay_seconds и игнорирование прежнего
поля; миграция delay в 5 с, диапазон 0–300 и целые значения; немедленная/300-секундная остановка;
изменение локальных настроек без смены канала и без продления срока; ручная запись не привязана
к локальному delay; обычный пустой tabs после внешнего завершения; новые варианты, найденные
в скане завершения, устаревшие; восстановление 60 с плюс локальные 12 с; снятие блокировки
чернового протокола при обновлении. Транспорт моделируется для всех poll=10–25 и минимального
N=2, включая одну неудачную попытку. Настоящий loopback WebSocket с mock проверяет N=2/4/10,
liveness после 2*poll и последующее окно N*poll.

**Не проверено:** реальные Chrome/Edge/Firefox и их lifecycle, системные баннеры ОС, подпись
Mozilla, фактический Go-сервер LocalMeetAssist и аудиозапись. Автоматические тесты используют
DOM/API-стабы и mock без аудио. Его журнал и UUID-кэш находятся в памяти; эти проверки не
доказывают атомарность bbolt и crash-гарантии настоящего сервера. Состояние его реализации
в §13 нормативного документа приведено автором спецификации.

Ручная приёмка: [TESTING.md](TESTING.md). Установка: [INSTALL.md](../INSTALL.md).
