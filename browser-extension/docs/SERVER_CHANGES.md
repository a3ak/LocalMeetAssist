# Совместимость с сервером 1.0

Расширения 1.4.0 соответствуют опубликованному [BROWSER_PLUGIN.md](BROWSER_PLUGIN.md).
В предоставленной спецификации §13 серверные изменения отмечены как реализованные.
Этот проект содержит расширения и тестовый mock; исходников Go-сервера здесь нет.

| Область | Требуемое поведение сервера | Поведение расширений |
|---|---|---|
| Hello/config | protocol_version=1, manual_tabs и recording_state | отправляют 1, проверяют config |
| Настройки | config не содержит stop_delay_seconds | локальные 0–300 с, исходно 5 |
| Потеря владельца | N*poll после закрытия, (2+N)*poll при молчании, N=2–10 | быстрые попытки с расчётом на N=2 |
| Обычный пустой tabs | сохраняет текущую запись | Stop только явной служебной командой |
| Ручные URL | record_manual/stop_manual с UUID, applied/noop/rejected | прежний механизм tabs, без новых CRUD прав |
| Глобальная запись | active/revision в state и heartbeat всем клиентам | синхронизируют Start/Stop и иконку |
| Внешнее завершение | idle, owner=false, prompt удалён, false/revision; набор URL сохраняется | удаляют контекст и отправляют обычный пустой набор |
| Revision | согласованное атомарное сохранение пары и публикация; после падения прежний true становится false с одним увеличением | старый контекст не восстанавливает другую запись |
| UUID | постоянная дедупликация по спецификации | повторяют тот же ID после обрыва |
| Быстрый browser restart | восстанавливает ту же сессию/client_id в grace | сохраняют источник, ждут controller 60 с плюс локальный delay |
| Ручная запись | не завершается от отсутствия плагина/пустых tabs | не привязывают её к страницам |

Новых endpoints, расширения прав plugin-токена или повторной серверной задержки ухода не требуется.
Серверное окно применяется при потере владельца; пока плагин жив, сроки controller/hold ведёт плагин.
N — только серверная настройка, получать его или stop_delay_seconds в config не требуется.
Проверки расширений с mock не подтверждают фактическую атомарность bbolt или аудиозапись Go-приложения.
Ручная интеграционная приёмка описана в [TESTING.md](TESTING.md).
