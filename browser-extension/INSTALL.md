# Установка расширений LocalMeetAssist

## 1. Подготовьте приложение

1. Запустите LocalMeetAssist с поддержкой **спецификации 1.0 (WebSocket-протокол 1)**. Наличие старых HTTP `/browser/state` и `/heartbeat` недостаточно.
2. В настройках приложения закрепите порт: `app.listen_port` не должен быть `0`. Запомните фактический порт, например `52469`.
3. В разделе **Интеграции → Браузер** включите интеграцию и создайте plugin-токен. Скопируйте значение `lma_pl_…`: оно показывается однократно.
4. Задайте маски встреч и режим в приложении: `auto` — начинать запись автоматически, `notify` — спрашивать перед записью. Расширение эти настройки получает от сервера.
5. Проверьте устройства аудио и разрешения **самого приложения**. Расширение аудио не захватывает.

## 2. Chrome

1. Распакуйте архив проекта в постоянную папку. Не переносите её после установки.
2. Откройте `chrome://extensions`.
3. Включите **Режим разработчика** в правом верхнем углу.
4. Нажмите **Загрузить распакованное расширение**.
5. Выберите папку **`localmeetassist-browser-extension/dist/chrome`**. Не выбирайте корень проекта или `src`.
6. Через значок пазла закрепите LocalMeetAssist на панели.
7. Нажмите значок LocalMeetAssist → **Настройки**.
8. Введите порт и токен → **Сохранить и подключиться**.
9. Дождитесь статуса **«Приложение подключено»** или **«Ожидание встречи»**.

Распакованное расширение сохраняется после перезапуска Chrome. Если политика компании запрещает режим разработчика, установку должен разрешить администратор. Архив браузерной сборки нужно сначала распаковать — Chrome не устанавливает такой ZIP обычным перетаскиванием.

## 3. Microsoft Edge

Повторите шаги для Chrome, используя **`edge://extensions`**. Папка сборки та же: **`dist/chrome`**.

## 4. Firefox: временная установка для проверки

1. Распакуйте проект.
2. Откройте **`about:debugging#/runtime/this-firefox`**.
3. Нажмите **Загрузить временное дополнение / Load Temporary Add-on**.
4. Выберите **`localmeetassist-browser-extension/dist/firefox/manifest.json`**.
5. Закрепите значок LocalMeetAssist через меню расширений, если он не виден.
6. Нажмите значок → **Настройки**, задайте порт и токен, сохраните.

**Временное дополнение удаляется при перезапуске Firefox.** Это способ проверки, а не постоянной установки. Для повторной загрузки выберите тот же manifest из той же папки. Поведение хранения данных при временной установке отличается от подписанного дополнения; при необходимости снова задайте настройки.

## 5. Firefox: постоянная установка

Для обычного Firefox Release/Beta нужен **подписанный Mozilla XPI**. Простое переименование ZIP в XPI не добавляет подпись.

1. Для сборки установите Node.js 22+ и выполните в корне проекта `npm run package`. Для установки уже готового расширения Node.js не нужен.
2. В [AMO Developer Hub](https://addons.mozilla.org/developers/) отправьте `artifacts/localmeetassist-firefox-1.4.0.zip` на подпись. Можно выбрать самостоятельное распространение (**unlisted**) без публичной карточки магазина.
3. Если Mozilla запросит исходники и инструкции сборки, предоставьте исходный проект и команды из README. Сборка не использует сторонние зависимости.
4. Скачайте полученный **подписанный XPI**.
5. В Firefox откройте `about:addons` → меню с шестерёнкой → **Установить дополнение из файла** → выберите подписанный XPI.
6. Подтвердите разрешения и настройте подключение.

В этом проекте Firefox-сборка **не подписана**. Учётная запись AMO и подпись не входят в архив. Если указанный ID уже занят другим проектом на AMO, перед первой публикацией замените `browser_specific_settings.gecko.id` своим уникальным ID и пересоберите. После публикации сохраняйте ID стабильным.

В manifest объявлены URL посещаемых страниц (`browsingActivity`) и данные авторизации (`authenticationInfo`). Они передаются только LocalMeetAssist на этом компьютере. Это не разрешение на отправку данных в облако.

## 6. Проверка работы

1. Выберите в приложении режим `notify`.
2. Откройте страницу встречи, подходящую под одну из масок, в **новой вкладке** и подождите 3 секунды. Страницы, уже открытые при первом запуске, игнорируются; F5 того же URL не делает их новыми.
3. Chrome/Edge: нажмите **Начать запись** в уведомлении или popup.
4. Firefox: нажмите само уведомление для подтверждения; **Не записывать** доступно в popup. Закрытие уведомления ответом не считается.
5. После запуска на значке LM появится **красная точка**. При ожидании ответа значок отмечен **чёрным ? на жёлтом фоне**, а подсказка предлагает нажать его. Авторитетный статус записи находится в приложении.
6. Откройте вторую подходящую вкладку: старая дублирующая вкладка не становится запасной управляющей. Закрытие controller запускает задержку; только новая страница того же GLOB до срока продолжает запись.
7. Закройте управляющую вкладку: плагин через настроенную задержку отправит stop_manual. Старые дубликаты не продолжают запись; новая вкладка того же GLOB до срока подхватит её.
8. Остановите запись вручную в приложении: все текущие подходящие вкладки станут устаревшими; новая вкладка или новый URL снова проходят обнаружение.

Бейдж **?** означает ожидающий вопрос; **!** — проблему соединения или авторизации. Откройте popup для пояснения.

## Настройки времени и уведомлений

В настройках расширения доступны «Максимальный возраст страницы» (180 по умолчанию, целое число 30–300 секунд), «Задержка перед реакцией» (3 по умолчанию, целое число 0–30 секунд) и «Задержка остановки» (5 по умолчанию, целое число 0–300 секунд). Задержка остановки отсчитывается после ухода с управляющей страницы только для собственной записи по GLOB. Значение 0 означает немедленную остановку. Изменение применяется к следующему отсчёту; уже начавшийся срок сохраняется. Изменение локальных временных настроек сохраняет соединение. Ручные записи приложения или кнопки Start не привязаны к вкладкам. После перехода на новую страницу встречи расширение ждёт указанное время и проверяет её снова. Закрытие или уход со страницы отменяет запуск. Уже принятая страница продолжает учитываться до выхода из неё; превышение возраста не останавливает запись.

При первом запуске, после перезапуска браузера и при потере сведений о возрасте существующие страницы игнорируются. Новое посещение встречи в старой вкладке учитывается при изменении адреса. Переключение активной вкладки и F5 того же адреса время не сбрасывают.

Если системный баннер не появляется, нажмите **Настройки → Проверить уведомление**. Проверка не запускает запись. Успешный ответ означает, что браузер принял уведомление; фактический показ зависит от разрешений уведомлений для браузера в ОС и режима «Не беспокоить». Жёлтый ? и вопрос по нажатию значка доступны независимо от баннера.

## 7. Обновление и удаление

- Chrome/Edge: обновите содержимое установленной папки `dist/chrome`, затем нажмите **Обновить/Reload** на карточке расширения. Заменяйте файлы в той же установленной папке и не добавляйте второй экземпляр из другой папки. Порт и токен сохраняются, отсутствующая локальная задержка остановки получит значение 5 секунд; возраст и задержка обнаружения сохраняются. После перезагрузки проверьте версию **1.4.0** в popup и откройте встречу в новой вкладке.
- Временный Firefox: после обновления файлов нажмите **Перезагрузить/Reload** в `about:debugging`.
- Подписанный Firefox: установите новую подписанную версию с прежним ID и увеличенным номером версии.
- При перегенерации plugin-токена сохраните новый токен в настройках каждого браузера/профиля. После отклонения токена бесконечных повторов подключения нет.
- Кнопка **Удалить настройки** удаляет токен и порт из расширения. Потеря канала не завершает запись: при необходимости завершите её в самом приложении.
- Для удаления расширения используйте стандартное меню браузера. При необходимости отзовите токен и выключите интеграцию в LocalMeetAssist.

## 8. Решение проблем

| Статус / проблема | Что проверить |
|---|---|
| Приложение недоступно | Приложение запущено, порт закреплён и совпадает; слушатель доступен на `127.0.0.1` |
| Токен отклонён | Создать/скопировать новый plugin-токен и сохранить его в расширении; токен должен начинаться с `lma_pl_` |
| Несовместимый ответ | Проверить соответствие сервера спецификации 1.0: protocol_version 1, capabilities, служебные URL, command ack, глобальный статус и revision; см. docs/SERVER_CHANGES.md |
| Страница не запускает запись | Открыта новая страница после запуска расширения, выдержана задержка, маски подходят, интеграция включена; нет ручной записи |
| Нет уведомления | Настройки → Проверить уведомление; проверить разрешение уведомлений для браузера в ОС и «Не беспокоить»; открыть popup по значку с ? |
| Другой браузер владеет сессией | Второй клиент не отвечает на чужой вопрос, но его явная кнопка Stop завершает глобальную запись |
| Firefox потерял расширение после перезапуска | Оно было установлено временно; для постоянной установки требуется подписанный XPI |
| Порт поменялся после запуска приложения | Зафиксировать `app.listen_port`, обновить настройки расширения |
| HTTPS-only приложение | Текущая версия использует `ws://`; нужен слушатель и протокол, соответствующие спецификации |

Диагностика background: Chrome — `chrome://extensions` → карточка LocalMeetAssist → service worker; Firefox — `about:debugging` → Inspect. Не публикуйте значение токена или содержимое `hello` из сетевого инспектора.

Официальные инструкции: [Chrome: загрузка распакованного расширения](https://developer.chrome.com/docs/extensions/get-started/tutorial/hello-world), [Firefox: временная установка](https://extensionworkshop.com/documentation/develop/temporary-installation-in-firefox/), [Mozilla: подпись и распространение](https://extensionworkshop.com/documentation/publish/signing-and-distribution-overview/).

## Новое управление 1.4.0

Кружок сверху запускает запись вручную, квадрат завершает текущую запись. Глобус открывает интерфейс приложения.
Вопрос по странице встречи подтверждается отдельной кнопкой, как прежде.
«Ожидать переключение» даёт 60 секунд; можно выбрать любую активную вкладку.
«Подходящих URL» открывает список с закрытием отдельных/всех подходящих вкладок.
Требуемый контракт сервера — [BROWSER_PLUGIN.md](docs/BROWSER_PLUGIN.md); памятка совместимости — [SERVER_CHANGES.md](docs/SERVER_CHANGES.md).


## Перезапуск браузера и потеря плагина — 1.4.0

При быстром полном перезапуске браузера сервер может ещё сохранять вашу браузерную запись в окне
`RECONNECT_GRACE = N × poll_interval_seconds`, где N — серверная настройка 2–10, исходно 4. При периоде 20 с и N=4 это 80 с после обнаруженной потери соединения. Если канал молчит без закрытия, сначала сервер обнаруживает потерю после двух периодов, затем отсчитывает окно: суммарно `(2 + N) × poll` от последнего принятого сообщения.
После подключения и подтверждения той же записи расширение показывает «Браузер перезапущен.
Выберите управляющую вкладку» и начинает 60 секунд ожидания. Выберите любую активную вкладку,
откройте новую страницу того же GLOB или продлите ожидание. Восстановленные старые страницы
автоматически управление не получают. Без выбора controller запись завершится через 60 секунд
плюс локально настроенная задержка остановки, отсчитываемые от подтверждения восстановления. Быстрое закрытие и повторный запуск браузера сохраняет запись до этого срока, если управление не выбрано.

Если браузер не вернулся за серверное окно, запись по GLOB завершает сервер. Ручную запись
приложения или кружка Start потеря плагина не останавливает. Если сервер уже завершил запись,
перезапуск браузера не запускает старую встречу снова.

Временная установка Firefox может удалять дополнение и его настройки при полном перезапуске.
Для приёмки восстановления после перезапуска используйте постоянно установленное подписанное дополнение.

Плагин сообщает, если порт не закреплён либо изменение закреплённого порта требует перезапуска
приложения. После изменения порта приложения обновите порт расширения.
